# axis:ppt1 — 글래스 스타일 현황 보고 덱

데이터 한 장(표·엑셀)을 **2장짜리 16:9 HTML 발표 덱**으로 만든다. 결과물은 HTML 1개(+ PDF 1개)다.
브라우저에서 바로 발표하고, `E` 로 글자를 고치고, `Ctrl+P` 로 PDF 를 뽑는다.

이 스킬은 `template.html`(완성된 예시 덱)을 **복사해서 데이터와 글자만 바꾸는** 방식이다.
레이아웃·효과·편집 엔진은 템플릿에 이미 들어 있으니 새로 짜지 않는다. 규칙은 `style.md` 에 있다.

---

## 0. 먼저 읽을 것

| 파일 | 내용 |
|---|---|
| `template.html` | 완성 덱. 1장 전체 현황 + 2장 항목별 비교. 데이터 블록·편집 엔진·인쇄 CSS 포함 |
| `style.md` | 디자인 토큰, 레이아웃 격자, 컴포넌트, 효과, 사용자 피드백으로 확정된 규칙 |
| `tools/export.py` | 헤드리스 Chrome 으로 스크린샷 검증·PDF 생성·런타임 오류 점검 |
| `tools/serve.py` | 저장 서버 — 브라우저에서 고친 글자가 즉시 원본 HTML 에 저장됨 |
| `tools/README.md` | 편집 키·저장·발표용 내보내기·모션 속도 조절 설명 (완성본과 함께 전달) |

## 1. 데이터 읽기

- 엑셀은 `openpyxl` 로 읽는다. **Windows 콘솔은 한글이 깨지므로 `PYTHONIOENCODING=utf-8` 을 붙여 실행**한다.
- 병합 셀·2단 헤더가 흔하다. `ws.merged_cells.ranges` 와 처음 3행을 먼저 찍어 구조를 파악한다.
- 원본 수치는 그대로 쓰고, 파생값(합계·비율·격차·추가 필요 건수)은 **직접 다시 계산해 원본과 맞는지 검증**한다.
  예: 인증지수 = (A+B)/C×100, 각 항목 합계가 총계와 일치하는지, 비율 분모가 무엇인지.
- 항목별 표가 있으면 "낮은 순" 정렬본을 만들고, 평균·목표 기준으로 그룹을 센다(평균 이하 n개, 목표 달성 n개, 실적 없음 n개).
- **파생 인사이트 3개**를 숫자로 뽑는다. 템플릿의 핵심 포인트 카드가 3칸이다.
  - 상위 그룹의 특징(어느 계열·어느 요인이 지수를 끌었나)
  - 하위 그룹의 규모(개수·재학생 비중)
  - 개선 레버(규모 큰 하위 항목이 평균만 달성하면 전체가 얼마나 오르나)

## 2. 2장 구성 (고정)

### 1장 전체 현황
| 영역 | 내용 | 템플릿 위치 |
|---|---|---|
| 좌측 | 필(pill) 2개 → 제목(핵심구 전체를 `<em>` 으로 강조) → 설명 3줄(굵은 숫자) → **산출 산식 카드**(항목 3개 + 결과 밴드) | `.hero`, `.formula`, `.fresult` |
| 우측 상단 | KPI 타일 4개 — **비율을 큰 숫자로, 인원수는 보조 문구로** | `.kpis .kpi` |
| 우측 중앙 | 반원 도넛 게이지(목표 대비 현재) + 달성률·격차·추가 필요 건수 3개 스탯 | `#gauge`, `.stats` |
| 우측 하단 | 분포 칩 4개(개수 + 재학생 수·전체 대비 비율) | `.chips .chip` |
| 각주 | 좌: 자료 출처 / 우: 비율의 분모 설명(우측 열 시작 위치에 맞춰 왼쪽 정렬) | `.foot`, `.foot-cap` |

### 2장 항목별 비교
| 영역 | 내용 | 템플릿 위치 |
|---|---|---|
| 제목 줄 | 제목 + 필(같은 줄) + 한 줄 부제(기준·평균·목표만) | `.s2-title` |
| 좌측 | 누적 가로 막대(낮은 순) + 평균선·목표선 + 평균 이하 영역 음영 + 막대 끝 값 라벨 | `#bars` |
| 우측 | 핵심 포인트 3개(아이콘 + 굵은 제목 + 2줄 설명) / 우선 관리 대상 목록(재학생 200명 이상·평균 이하 등 기준 명시) | `.insight`, `.priority` |

장수는 2장으로 고정한다. 내용이 더 있으면 덱을 하나 더 만들지, 장을 늘리지 않는다(레이아웃이 1600×900 에 맞춰 있다).

## 3. 만들기

1. `${CLAUDE_SKILL_DIR}/template.html` 을 작업 폴더에 결과 파일명으로 복사한다. 파일명은 `{연도}_{주제}_현황보고_A_글래스.html` 처럼 한글 그대로 둔다.
2. `<script>` 의 **DATA 블록**을 바꾼다.
   ```js
   const DEPTS = [ {name:'표시명', full:'정식 명칭(툴팁용, 선택)', n:재학생, a:핵심인증자, b:전공인증자, e:비교과, idx:지수}, … ]; // 낮은 순
   const TOTAL = {n, a, b, e, idx, core, major, target};
   const PRIORITY = ['우선 관리 대상 표시명', …];   // 차트 라벨을 굵게, 2장 목록에 표시
   ```
   `name` 은 차트 y축 라벨이므로 12자 이내로 줄이고, 긴 정식 명칭은 `full` 에 둔다.
3. HTML 글자를 바꾼다. 바꿔야 할 자리는 모두 **편집 대상 선택자 안**(h1·p·.k·.v·.s·.t·.n·.insight li b/p·.pnote·.foot span…)에 있다. 숫자 타일은 `data-count`(목표값)·`data-decimals` 와 표시 글자를 **둘 다** 바꾼다.
4. 산식 카드(`.frow`·`.fresult`), 게이지 중앙 숫자, 스탯 3개, 칩 4개, 각주 분모 설명, 2장 부제·핵심 포인트·우선 관리 기준 문구를 데이터에 맞게 쓴다.
5. 차트는 그대로 둔다. 데이터 형태가 다르면 Chart.js 공식 샘플에서 고른다(`samples/other-charts/doughnut`, `samples/bar/stacked` + `indexAxis:'y'`). 색은 `style.md` 의 두 가지 시리즈 색만 쓴다.
6. 아이콘은 템플릿의 `<symbol id="ic-…">` 에서 고른다(badge·cap·people·target·star·chart·up·alert·cube·doc·stairs). 새 아이콘이 필요하면 같은 타일 규격(96×96, `#tile` 베이스 + 흰 도형)으로 그린다.

### 바꾸면 안 되는 것
- `:root` 토큰, 1600×900 슬라이드 구조, `.rv` 등장 순서(`--i`), 인쇄 CSS, `data-editor` 블록 3개(편집 CSS·도구·스크립트), `ensureChart`(CDN 대체 로드), `finishCounts`(인쇄 시 숫자 고정).
- 스크립트가 만드는 요소(우선 관리 목록 행·점 내비게이션)를 HTML 에 직접 쓰지 않는다. 편집 저장 시 `html()` 이 걷어내고 다시 만든다.

## 4. 검증 — 만들고 나서 반드시

```bash
python "${CLAUDE_SKILL_DIR}/tools/export.py" check "덱.html"           # node --check + 런타임 오류·목록 행 수
python "${CLAUDE_SKILL_DIR}/tools/export.py" shot  "덱.html"           # 1·2장 스크린샷 (등장 애니메이션을 완료 상태로 고정해 찍음)
```
- 스크린샷은 **반드시 눈으로 본다**: 넘침·겹침(특히 2장 우측 목록의 마지막 행과 참고 문구), 각주와 하단 내비의 간격, 칩 글자 줄바꿈.
- `export.py` 는 GPU 를 켠 채 찍는다. `--disable-gpu` 로 찍으면 3D 변환된 카드와 캔버스가 비어 보여 오판한다.
- 헤드리스에서는 애니메이션 시계가 진행되지 않는다. 속도 판단은 `document.getAnimations()` 의 duration 으로 하고(`export.py anims`), 눈 검증은 완료 상태 사본으로 한다.
- cdnjs 가 막힌 환경을 가정해 `--block-cdnjs` 로 한 번 더 찍으면 jsdelivr 대체 로드가 동작하는지 확인된다.

## 5. PDF

```bash
python "${CLAUDE_SKILL_DIR}/tools/export.py" pdf "덱.html"             # 같은 이름의 .pdf, 2쪽, 1200×675pt(16:9)
```
인쇄 CSS 가 슬라이드 1장 = 1쪽으로 잡고, 내비·편집 도구·모션을 뺀다. `beforeprint` 에서 카운트업과 차트를 최종값으로 고정하므로 숫자가 중간값으로 찍히지 않는다. 사용자가 PDF 를 직접 고쳤으면 PDF 를 덮어쓰지 말고 **PDF 의 글자 좌표를 원본 렌더와 비교해 HTML 에 역반영**한다(`pymupdf` 로 span 단위 비교).

## 6. 전달

- 저장 서버로 열어 주면 편집이 즉시 파일에 저장된다: `python "${CLAUDE_SKILL_DIR}/tools/serve.py" --open "덱.html"`
- 완성 안내에 다음을 한 줄씩 적는다: 파일 경로, 키(`←→` 이동 · `F` 전체 화면 · `E` 편집 · `Ctrl+S` 저장 · 마지막 장 `[편집 기능 삭제]`), 모션 속도는 `:root` 의 `--slow`(현재 0.4, 클수록 느림), Chart.js·폰트는 CDN 이라 인터넷 필요.
- 장별 한 줄 요약표를 같이 보여 준다.
  ```
  01 전체 현황   KPI 4 · 산식 · 게이지 22.57/32.1 · 분포 칩
  02 항목별 비교 누적 막대 24개 · 핵심 포인트 3 · 우선 관리 7개
  ```

## 7. 확정된 규칙 (사용자 피드백에서 나온 것 — 어기지 않는다)

1. **비율이 헤드라인, 인원은 보조**: 모든 KPI 타일은 `1.57%` 를 크게, `인증자 71명` 을 아래 작은 글자로. 인원수를 큰 숫자로 올리지 않는다.
2. **비율의 분모를 적는다**: 칩·타일의 % 가 "전체 재학생 대비"인지 "해당 역량 대비"인지 각주에 명시한다.
3. **슬라이드에 UI 안내 문구를 쓰지 않는다**: "마우스를 올리면…", "표로 보기" 같은 조작 힌트는 발표 자료에 넣지 않는다. 툴팁·호버는 있어도 글로 적지 않는다.
4. **우측 인사이트 카드가 주인공**: 2장은 차트를 좁히고(1fr 560px) 핵심 포인트·우선 관리 카드를 키우고 강조선을 넣는다.
5. **산식 그림은 크게**: 항목 3개 + 결과 밴드 두 줄 구성. 제목의 핵심구는 단어가 아니라 구 전체(`학생역량 인증지수`)를 강조한다.
6. **각주 배치**: 좌 "자료: …", 우 비율 설명을 우측 열 시작선에 맞춰 왼쪽 정렬. "차트 Chart.js …" 같은 도구 표기는 넣지 않는다.
7. **모션은 느리고 자연스럽게, 그러나 멈추지 않게**: `--slow:0.4` 가 확정값. 처음 버전(빠름)과 정지 버전 모두 거부됐다.
8. **`prefers-reduced-motion` 으로 애니메이션을 0.001초로 줄이지 않는다**: Windows "애니메이션 효과 끄기" PC 에서 무한 반복 모션이 1ms 루프가 되어 떨린다. 이 덱은 OS 설정과 무관하게 재생한다(`const reduced = false`).
9. **줄바꿈은 단어 단위**(`word-break:keep-all`), 폰트는 나눔스퀘어(jsdelivr), 차트는 Chart.js 4.5(cdnjs, 실패 시 jsdelivr).
10. 숫자가 들어가는 장에만 차트를 넣고, 차트 종류는 Chart.js 공식 샘플에서 고른다.

## 8. 체크리스트

```
□ DATA 블록 합계가 원본 총계와 일치 (A+B, 비율, 지수)
□ KPI 4개: 비율 헤드라인 · 인원 보조 · data-count 와 표시 글자 일치
□ 1장 각주 우측에 분모 설명, "차트 …" 표기 없음
□ 2장 부제에 조작 힌트 없음 · 표로 보기 버튼 없음
□ 우선 관리 목록 마지막 행이 참고 문구와 안 겹침 (스크린샷 확인)
□ node --check 통과 · 런타임 오류 0 · 목록 행 수 = PRIORITY 개수 + 1
□ --block-cdnjs 에서도 차트가 그려짐
□ PDF 2쪽, 숫자 최종값, 내비·편집 도구 없음
□ data-editor 블록 3개 · id="edit" · id="final" 존재
```
