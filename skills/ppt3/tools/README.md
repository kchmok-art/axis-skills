# 덱 조작·편집 안내 (axis:ppt3)

이 HTML 덱은 브라우저에서 바로 발표합니다. 인터넷이 필요합니다(차트 Chart.js 와 Pretendard 폰트를 CDN 에서 받습니다).

## 발표

| 동작 | 방법 |
|---|---|
| 다음 / 이전 장 | `→` `←` · `Space` · `PageDown/Up` · 빈 곳 클릭 · 휠 · 스와이프 |
| 처음 / 끝 | `Home` / `End` |
| 전체 화면 | `F` |
| 구간 이동 | 상단 메뉴 버튼 |
| 화면 배율 | `[` 축소 · `]` 확대 · `\` 원래대로 (뒷자리에서 글씨가 작을 때. 브라우저에 기억됨) |
| 특정 장으로 열기 | 주소 끝에 `#12` |

## 편집 (RDDcat/maro-ppt 편집 엔진 이식)

| 동작 | 방법 |
|---|---|
| 편집 켜기/끄기 | 하단 `[편집]` 또는 `E` (한글 `ㄷ` 도 됨) |
| 글자 고치기 | 글자를 클릭하고 타이핑. 서식·구조는 그대로(plaintext). 그림(SVG) 글자는 더블클릭 |
| 저장 | 저장 서버로 열었으면 고치는 즉시 원본에 저장(0.4초 뒤). `file://` 로 열었으면 `[저장]` 또는 `Ctrl+S` (처음 한 번만 파일 선택) |
| 되돌리기 | `[원래대로]` |
| 발표용 파일 | 마지막 장에서 `[편집 기능 삭제]` → `{이름}-발표용.html` 로 따로 저장 (효과·차트·장 넘기기는 그대로, 편집만 빠짐) |

- 편집 중에는 `←` `→`·휠·클릭으로 장이 넘어가지 않습니다. `Esc` 로 글자 상자에서 나옵니다.
- 저장 안 한 편집은 브라우저(localStorage)에 남아 새로고침해도 같은 자리에 다시 붙습니다.

### 도식 장 (박스 + 화살표)

편집을 켠 채 도식이 있는 장에 가면 하단에 도식 도구가 나타납니다.

| 동작 | 방법 |
|---|---|
| 옮기기 / 크기 | 박스를 끌기 / 오른쪽 아래 손잡이 끌기 |
| 글자 | 박스 더블클릭 → 제목·설명 편집 |
| 새 박스 | `[박스]` |
| 화살표 | 박스를 고른 뒤 `[연결]` → 다음에 누르는 박스로 화살표. 화살표 라벨은 라벨을 더블클릭 |
| 복제 / 삭제 | `[복제]`(`Ctrl+D`) / `[삭제]`(`Delete`) |
| 모양 | `[모양]` — 박스: 흰 → 잉크 → 그라디언트 · 화살표: 실선 ↔ 점선 |
| 휘기 | `[휘기]` — 화살표 곡률: 직선 → 오른쪽 → 왼쪽 |

## 저장 서버 (권장)

```bash
python tools/serve.py --open "덱.html"   # 띄우고 브라우저로 연다
python tools/serve.py --stop             # 끄기
```

- `127.0.0.1:8765` 에서만 듣고, `--open` 한 파일의 폴더 아래 `.html` 만 읽고 씁니다. (포트: `MARO_PPT_PORT`)
- 열린 탭이 1.5초마다 파일을 확인합니다. 에이전트가 파일을 고치면 탭이 알아서 새로고침해 그 변경을 받습니다(보던 장 유지).
- 저장 직전에 파일이 바뀌었으면 서버가 409 로 거절하고, 탭은 새로고침한 뒤 사용자 편집을 다시 붙여 저장합니다.

## PDF

`Ctrl+P` → 대상 "PDF 로 저장", 여백 "없음", 배경 그래픽 켜기. 슬라이드 1장 = 1쪽(1600×900)으로 찍힙니다.
또는 `python tools/export.py pdf "덱.html"`.

## 스킬로 만들 때 체크리스트

```bash
grep -c 'id="edit"'  "$f"   # 1
grep -c 'id="final"' "$f"   # 1
grep -oE '<(style|span|script)[^>]* data-editor>' "$f" | wc -l   # 4 (편집 CSS · 도구 · 편집 스크립트 · 도식 편집기)
```

- 글자는 편집 대상 선택자 안에 둡니다(`h1 h2 h3 h4 p .lead .kicker .band .pill .tag .step b/span ul.list li .stat .v/.l/.s .big .prompt .src .chip em/b/small svg text`).
- 스크립트가 만들어 넣는 요소(`.dg-wire .dg-fit .dg-grip`, 인라인 transform)는 저장 시 `html()` 이 걷어냅니다. 브라우저 콘솔 `__deckHtml()` 로 저장될 HTML 을 확인할 수 있습니다.
