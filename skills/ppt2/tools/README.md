# 덱 편집 기능 (maro-ppt 편집 엔진 이식)

이 스킬로 만든 HTML 덱에는 발표 중·발표 전에 쓰는 편집 기능이 들어 있습니다.
[RDDcat/maro-ppt](https://github.com/RDDcat/maro-ppt)(MIT)의 인라인 편집·저장·발표용 내보내기 부분만 가져와 이 덱 구조에 맞게 손본 것입니다.
도식(.dg) 편집기는 이 덱에 도식 구조가 없어 넣지 않았습니다.

## 키와 버튼 (하단 내비게이션 오른쪽)

| 동작 | 방법 |
|---|---|
| 편집 켜기/끄기 | `[편집]` 또는 `E` (한글 입력 상태의 `ㄷ`도 됨) |
| 고치기 | 글자를 클릭하고 그대로 타이핑. 서식·구조는 바뀌지 않음(plaintext-only) |
| 저장 | 저장 서버로 열었으면 고치는 즉시 원본에 저장(0.4초 뒤). file:// 로 열었으면 `[저장]` 또는 `Ctrl+S` (처음 한 번만 파일 선택, 이후 자동 저장) |
| 되돌리기 | `[원래대로]` |
| 발표용 파일 | 마지막 장에서 `[편집 기능 삭제]` → `{이름}-발표용.html` 로 따로 저장 (편집 기능만 빠지고 효과·차트·장 넘기기는 그대로) |

- 편집 중에는 `←` `→`·휠·스와이프로 장이 넘어가지 않습니다. `Esc`로 글자 상자에서 빠져나옵니다.
- KPI 숫자(카운트업 대상)를 고치면 애니메이션 목표값도 같이 바뀝니다.
- 저장 안 한 편집은 "원래 글자"와 함께 브라우저(localStorage)에 남아, 새로고침해도 같은 자리에 다시 붙습니다.
  그 사이 파일이 바뀌어 자리를 못 찾으면 덮어쓰지 않고 따로 보관합니다(콘솔 `deckLost`).
- 저장되는 HTML 에서는 스크립트가 만든 요소(우선 관리 목록 행·표·점·배경 큐브·인라인 transform)를 걷어내므로,
  다시 열어도 중복 생성되지 않습니다.

## 저장 서버 (권장)

```bash
python tools/serve.py --open "덱.html"   # 띄우고 브라우저로 연다
python tools/serve.py --stop                                                 # 끄기
```

- `127.0.0.1:8765` 에서만 듣고, `--open` 한 파일의 폴더 아래 `.html` 만 읽고 씁니다. (포트: `MARO_PPT_PORT`)
- 열린 탭이 1.5초마다 파일을 확인합니다. 에이전트가 파일을 고치면 탭이 알아서 새로고침해 그 변경을 받습니다(보던 장 유지).
- 저장 직전에 파일이 바뀌었으면 서버가 409로 거절하고, 탭은 새로고침한 뒤 사용자 편집을 다시 붙여 저장합니다.

## 스킬로 만들 때 체크리스트

```bash
grep -c 'id="edit"'  "$f"   # 1
grep -c 'id="final"' "$f"   # 1
grep -oE '<(style|span|script)[^>]* data-editor>' "$f" | wc -l   # 3 (편집 CSS · 도구 · 스크립트)
```

- 글자는 반드시 편집 대상 선택자 안에 둡니다(`h1 h2 h3 p .sub .pill .brand-t .kpi .k/.s [data-count] .fterm .k/.v .stat .k .legend span .chip .n/.t .insight li b .pnote .foot span` 등).
- 스크립트가 만들어 넣는 요소가 늘어나면 편집 스크립트의 `html()` 에서 걷어내는 목록에 추가합니다.
- 브라우저 콘솔에서 `__deckHtml()` 로 저장될 HTML 을 확인할 수 있습니다.

## 모션 속도 조절

- HTML 의 `:root` 에 있는 `--slow` 값이 상시 모션(부유 아이콘·블롭·큐브 회전·네트워크·펄스)의 배속입니다. `1` = 기준, `2` = 두 배 느리게, `0.4` = 2.5배 빠르게(현재 값), 클수록 느려집니다. 등장·전환 애니메이션에는 영향이 없습니다.
- Windows 설정 > 접근성 > 시각 효과 > "애니메이션 효과" 가 꺼져 있어 Chrome 이 `prefers-reduced-motion: reduce` 로 동작합니다. 그래서 예전 버전의 접근성 규칙(모든 애니메이션 0.001초)이 무한 반복 모션을 1ms 루프로 만들어 아이콘이 떨리듯 보였습니다. 지금 버전은 그 설정과 무관하게 디자인된 속도로 재생합니다(스크립트의 `const reduced = false`).
